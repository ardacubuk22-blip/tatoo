# سایت عتیقه‌فروشی

یک سایت تک‌صفحه‌ای ساده و شیک برای معرفی یک کسب‌وکار عتیقه‌سازی/عتیقه‌فروشی،
با الهام از حال‌وهوای سایت‌های گالری عتیقه (رنگ‌های گرم، فونت خوانا، چیدمان مینیمال).

## ساختار پروژه

```
index.html          صفحه اصلی
css/style.css        استایل سایت
js/script.js         منوی موبایل و رفتار ساده
assets/images/        محل قرارگیری عکس‌های واقعی
```

## شخصی‌سازی

در `index.html` موارد زیر را با اطلاعات واقعی جایگزین کنید:

- `[نام مغازه عتیقه]` در تگ `<title>`، هدر و فوتر
- متن بخش «درباره ما»
- عکس‌ها: هر `placeholder-img` را با `<img src="assets/images/xxx.jpg" alt="...">` جایگزین کنید
- کارت‌های بخش «مجموعه»: نام و توضیح هر قطعه
- `[آدرس فروشگاه]`، `[شماره تماس]`، `[ساعات کاری]` و لینک اینستاگرام در بخش تماس

## اجرای محلی

فایل `index.html` را مستقیم در مرورگر باز کنید، یا با یک سرور ساده:

```bash
npx serve .
```

## انتشار روی GitHub Pages

1. به تنظیمات ریپو در گیت‌هاب بروید: Settings → Pages
2. Source را روی شاخه‌ی مورد نظر (مثلاً `main`) و پوشه‌ی `/ (root)` قرار دهید
3. آدرس سایت بعد از چند دقیقه در همان صفحه نمایش داده می‌شود
